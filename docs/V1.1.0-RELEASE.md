# Bookstore Professional v1.1.0

## Release summary

v1.1.0 is the professionalization and security-hardening milestone for the online bookstore management system.

## Included

- request correlation IDs
- structured audit logging and admin audit view
- system diagnostics and operational request metrics
- authentication/session security hardening
- CSRF and secure-cookie protections
- login brute-force protection with HTTP 429 throttling
- API authorization boundaries for admin and customer roles
- production secret externalization
- minimal Actuator exposure
- Docker healthcheck alignment
- Spring Security startup circular-dependency fix
- CI and Docker verification

## Verification highlights

- application health endpoint returns HTTP 200
- Docker application and MySQL containers report healthy
- storefront returns HTTP 200
- invalid credentials return HTTP 401
- repeated login failures trigger HTTP 429 with Retry-After
- develop branch is clean and synchronized
- release tag: `v1.1.0`
