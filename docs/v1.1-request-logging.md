# V1.1 Request Logging

The V1.1 request correlation layer uses `X-Request-Id` for end-to-end request tracing.

- A valid caller-provided ID is preserved.
- Missing or unsafe IDs are replaced with a server-generated UUID.
- The ID is placed in the logging MDC while the request is processed.
- Completion logs include HTTP method, path, status, duration, and request ID.
