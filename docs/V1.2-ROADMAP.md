# v1.2 Roadmap

## Goal
Build on the stable v1.1.0 foundation without disturbing the production-hardened baseline.

## Priority 1 — Release and deployment quality
- Add a complete deployment guide.
- Document required production environment variables.
- Document Docker-based startup, health checks, and rollback.
- Add a v1.1.0 release notes document.

## Priority 2 — Test and observability depth
- Expand authorization regression coverage to important business endpoints.
- Add integration coverage for login rate limiting and audit events.
- Add negative-path tests for diagnostics and admin APIs.
- Improve operational error messages without exposing sensitive internals.

## Priority 3 — Product experience
- Improve catalog search and filtering.
- Improve book/category management workflows.
- Improve cart and order UX.
- Add clearer customer-facing validation and error states.

## Priority 4 — Platform evolution
- Review database indexes and slow queries.
- Add pagination where collection endpoints need it.
- Review caching opportunities.
- Add a documented backup/restore procedure.

## Definition of done
Each v1.2 feature should have:
- automated tests,
- CI coverage,
- documented behavior,
- a clean rollback path,
- and no regression in the v1.1.0 security baseline.
